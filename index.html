How RouteFlex works

Enter a depot/start postcode and one or more delivery postcodes. RouteFlex validates the postcodes, optimises the order, builds the road route and shows the stops for you.

Voice input

Use the microphone buttons beside the start postcode and delivery postcodes where your browser supports Web Speech Recognition. Spoken postcodes are cleaned into standard postcode format.

Driver Mode

Use Driver Mode on a phone for a simplified route view with current delivery, progress, leg distance/time, navigation and delivery controls.

Navigation & export

Navigate opens the current stop in Google Maps or Apple Maps where available. Route export downloads a CSV style route file for spreadsheet use.

Live traffic

RouteFlex uses available routing data from the current free/static setup and does not provide live traffic unless a future traffic provider is added.
